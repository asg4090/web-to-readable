# Changelog

## 2.0.0 — 2026-10-22

- Prepare the initial portable open-source distribution with Chinese and English documentation.
- Package the `web_to_readable` MCP server and CLI with an installable Python module.
- Return complete Markdown inline in one tool call; save JSON, offline HTML, and local images.
- Keep PDF export optional and disabled by default.
- Include continuation reads, synthetic integration tests, CI configuration, and an MIT license.
- Remove machine-specific paths, exported articles, and local verification artifacts from release sources.
